# 如何在塞尔达完成载人航天 · 究极手复刻 · 机制拆解 05

《塞尔达传说 王国之泪》的究极手是怎么把东西粘住的？这里用 **Three.js + Rapier 物理引擎** 写了一份原创教学复刻：抓取、45° 旋转、找粘接点、粘合（关节 / 合并 / 围攻式会断）、整坨搬运、风扇 / 轮子 / 热气球 / 火箭动力，以及一键载人火箭。

代码由 **Claude Opus** 编写，粑粑柑负责提需求和按发射按钮。

- 在线试玩：https://mechanics-breakdown.pages.dev/05-ultrahand/
- 解析视频：B站 / 抖音搜「粑粑柑（梭哈ai版）」· 机制拆解 05

## 运行

```bash
npm install
npm run dev        # http://127.0.0.1:8025/
```

页面是 ES Module，必须通过 http 打开。`npm run build` 会打包出 `dist/05-ultrahand/`（压缩后的单文件版本）。

## 操作

WASD 走 · 鼠标看 · 左键抓起 / 松手（靠近别的零件自动粘上）· 滚轮推远拉近 · Q/E 左右转 45° · R/F 前后翻 45° · X 拆下 · 右键松手不粘 · V 开关动力 · 1–0 召唤零件（0 是橘子乘客）。右侧面板可以切换粘合方式、分层开关和求解器迭代次数。

## 代码结构

| 文件 | 作用 |
|---|---|
| `src/sim.js` | 物理世界：Rapier 刚体、粘合图（glue graph）→ 关节 / 合并刚体 / 可断关节，同一坨零件不互相碰撞，零件上限 21，风扇 / 轮子 / 热气球动力 |
| `src/ultrahand.js` | 究极手：射线抓取、速度驱动（不瞬移）、相对玩家朝向、45° 吸附、最近点预览、松手吸附 + 粘合、整坨搬运 |
| `src/parts.js` | 零件表（形状、密度、动力参数） |
| `src/presets.js` | 一键搭好的小车 / 热气球飞板 / 木板桥 |
| `src/view.js` | 渲染：程序化贴图、草地、远山、菲涅尔发光外壳、光束、胶水团、粒子、Bloom |
| `src/state.js` | 每帧画面状态（纯数据），网页和视频共用 |
| `src/director.js`, `src/shots.js` | 视频镜头：脚本化操作在物理里确定性地跑一遍，逐帧存状态 |
| `app.js`, `index.html`, `site*.css`, `method.html` | 可玩网页 + 实现方法说明 |
| `film*.js/html/css`, `demo_film.*`, `tools/` | 视频逐帧渲染管线（headless Chrome → ffmpeg） |
